# 传统笔墨的来源与学习记录

后续逐项阅读已扩展为 [100项笔墨技法学习总册](learning/README.md)。下文保留首轮八份主要资料的实际阅读边界；本轮新增的正文、操作解释、异说与未确证问题均在总册逐项登记。

首轮查阅：2026-11-19。研究对象是传统水墨画与古代书画的用笔、用墨及组织方法。“古董字画”在这里按古代作品理解，不把泛黄、污渍、裂纹等做旧效果当作古人笔法。

本记录是一份可扩展的学习底稿，不是“所有中国画笔法”的封闭清单。不同画科、书体、时代、师承对名称的用法可能不同；名称、异名和长短／大小变体也不宜直接累加为已掌握的技法数量。代码目录列出一个术语，只表示研究范围已被记录。

## 从来源得到的第一批结论

1. **先分层，再编写函数。** 单国强的总目将笔、墨、水分开，《书谱》又区分执、使、转、用。`中锋`、`浓墨`、`破墨`、`披麻皴`、`白描`、`行书`不在同一层级，不能都做成一个笔刷预设下拉框后称为补齐。
2. **中锋、侧锋不是圆笔、扁笔的同义词。** 《续书谱》谈的是笔锋在笔画中的关系，王诜作品说明也把同幅画的不同锋法分别用于对象。当前软件的 `round`／`flat` 只是接触形状的简化；要研究锋法，还需让方向、偏置、提按、转向及边缘承墨一起变化。
3. **提按、转折、起收是沿路径发生的动作。** 尖起、逆入、回锋、出锋不能仅靠端点贴一个圆帽；圆转也不等于把所有节点全局平滑。第一批原型应保存生成后的实际路径与压力，而不是只保存一个传统名称。
4. **墨态不等于墨法。** 浓、淡、干、湿、焦涉及可见状态和材料关系；积墨、破墨、泼墨涉及先后、组织及相互作用。加深颜色不自动成为焦墨，多遍透明填色不自动成为积墨，随机散点不自动成为泼墨。
5. **“墨分五色”不是唯一固定的五级灰度表。** 本轮PDF并列“五墨”“六彩”的说法，其中还混合干湿等维度。软件可以提供对照色阶，但不应声称灰度色板已等同传统墨法。
6. **皴法服务于造形，而不是附在任意轮廓上的纹理。** 披麻的错落交搭和斧劈的横扫、切面必须联系山石走势；所谓长短、大／小也要在具体画家和作品范围里判断。此前剑峰例子的纵向长劈只是一种场景实验，不能代表斧劈皴全部范围。
7. **同名并不保证一种稳定算法。** 抱石皴的来源强调融合与破笔聚散，说明画家可以综合多种手段形成个性面貌。给同一随机纤维函数换名字，不能算学会多个皴法。
8. **飞白需要分清语境。** 可见的枯笔露纸、书法史中的飞白及某种材料接触状态相关但并不完全等同。本库当前先记录“顺笔势的断白”这一可观察目标，不从一个 `dryness` 数值推导历史画法验收。

## 学习范围与分批次序

| 层次 | 第一轮应记录的对象 | 实现前的关键问题 |
| --- | --- | --- |
| 基础运笔 | 中侧偏锋、顺逆锋、藏露锋、回锋出锋、提按顿挫、转折、疾涩、聚散锋 | 动作发生在何处？路径、压力、接触方向和墨迹有何不同？哪些词在来源中只是提及？ |
| 点迹与短笔 | 单点的起按提收、圆点／横点／竖点、成组点迹 | 单点能否连续编辑？是否变成重复印章？改变位置、大小或方向后能否保留用笔？ |
| 墨态与墨法 | 浓淡、干湿、焦墨、断白，以及积墨、破墨、泼墨、渲染、烘托 | 先区分色值、含墨、含水、先后与层间作用。当前可做的视觉近似和暂未模拟的材料过程分别是什么？ |
| 山石皴擦 | 先细学披麻、斧劈，再查折带、解索、乱柴、牛毛、卷云等 | 需要什么山石结构？线、面、点如何组织？同名在不同画家处有什么差别？ |
| 树木与花卉点法 | 苔点、点叶、夹叶、松针、竹叶，以及介字／个字等组点 | 先建立有来源的图式，不从名称猜一套固定几何。枝叶关系与聚散比点的数量更关键。 |
| 人物与花鸟勾描 | 白描、双勾、没骨及衣纹线描类型 | 方法、题材和线条风格要分开；“十八描”需继续寻找可靠版本和作品例证，不能批量用18个压力模板代替。 |
| 书法运笔与点画 | 起收转折的共通动作，再分别研究点、横、竖、撇、捺、钩等 | 笔画要放在结字、向背和书体里理解；永字八法是学习线索，不是全部古代书法的穷尽分类。 |
| 水法与纸性 | 水破墨、墨破水、渍水、撞水、洒水等 | 目前多数只有术语总目，不能标记成已掌握；需要补操作说明、干湿时序与纸性参考后，再决定Canvas近似的边界。 |

第一批优先落实**基础运笔和点迹原语**，并把它们保持为可组合、可编辑的数据。墨法、水法和更多皴法、点叶、衣纹分类继续保留为逐项学习任务；目录中的“待研究”不进入可执行接口冒充成品。

## 每项技法的学习闭环

1. **出处。** 实际打开资料，记标题、作者／机构、年代或未核实项、访问日期、链接和读到的范围；区分术语提及、动作解释、作品观察与自己的推断。
2. **动作与目标。** 用可观察的语言描述起收、宽窄、转向、断续、边缘承墨及组织关系，记录容易误画成什么。禁止只写“更有古意”“更像国画”。
3. **算法假设。** 明确准备用路径、压力、方向、接触偏置、局部墨量还是图层时序去近似；传统术语不能充当算法说明。
4. **同题样片。** 固定尺寸、纸色、种子、路径和后端，只改变一个目标变量。保存源码、参数、实际数据和输出。
5. **换形样片。** 更换方向、曲率、急转、长宽或区域，检查改进是否只适用于原例；再看局部和缩略图。
6. **分别记录结果。** 数据确定性、浏览器成功出图、术语证据、实际视觉改善和人工认可分别登记。测试通过不自动把状态改为艺术验收。
7. **进入组合。** 单笔已有可说明的适用范围后，再用于山石、树木、衣纹和完整画面；组合失败时回查结构与笔势，不能一味加笔数或加噪声。

学习目录的数据定义见 [technique-catalog.ts](../src/technique-catalog.ts)，基础运笔原型见 [brushwork.ts](../src/brushwork.ts)。目录的证据、实现和视觉检查状态相互独立：有出处但未实现、有原型但尚待看图，都属于正常而明确的学习阶段。
