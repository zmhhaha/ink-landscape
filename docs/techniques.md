# 技法与参数

本库用程序化笔触探索水墨视觉语言。下述传统名称仅用于说明灵感来源，目前是工程原型，尚未通过艺术效果验收。应通过实际渲染与参考对照判断适用范围，不能根据函数名称宣称达到某种传统画法。

## 基础笔触：stroke

输入是一组 `{ x, y, pressure? }` 点。调用者决定路径和提按变化，库沿路径生成笔触。

- `width`：笔触宽度；`ink` 和 `opacity`：墨色与透明度。
- `dryness`：0 表示更连续的湿实笔迹，1 表示更破碎的枯笔效果；这是视觉近似，不是含水量的物理测量。
- `nib`：`round` 或 `flat`；`tipAngle`：笔头方向，单位为弧度。
- `clip`：可选裁切区域，使用 `{ x, y }` 点组成的轮廓。
- `seed`：控制笔触的随机变化，便于复现。

例如，山石外轮廓可使用压力起伏明显的线，内部结构则用更轻、更短的笔触。增加笔触数量不能替代清楚的山体结构与走向。

## 墨洗：wash

`wash(outline, options)` 在调用者提供的轮廓内叠加墨色。

- `ink`、`opacity`：控制墨色和透明度。
- `roughness`：控制边缘变化。
- `passes`：控制叠加次数。
- `seed`：控制可重复的随机变化。

先分清近、中、远景的明度关系，再安排墨洗层次。这里没有真实的纸纤维吸水、流体输运或毛细扩散模拟；Shader 后端也尚未实现。

## 皴擦：cun

`cun(outline, options)` 在区域内生成一组普通笔触。返回数据被冻结；调用者可用对象展开与 `map` 重建选定笔触及场景，再交给渲染器。JavaScript 也可用 `structuredClone(builder.snapshot())` 取得可写副本；TypeScript 中该克隆仍保留 `readonly` 类型，重建方式见 README。

| 参数 | 含义 |
| --- | --- |
| `technique: 'pima'` | 受披麻皴启发的长线皴擦近似 |
| `technique: 'axe'` | 受斧劈皴启发的短切皴擦近似 |
| `count` | 计划生成的笔触数量 |
| `length` | 皴擦长度参数，使用场景坐标单位 |
| `direction: { x, y }` | 整体走向向量 |
| `flow(point)` | 随位置变化的方向场；用于沿山体结构调整笔势 |
| `idPrefix` | 生成笔触的身份前缀 |

还可使用基础笔触的宽度、枯湿、墨色和时间选项。`flow` 仅在生成阶段运行，返回的快照不包含函数；为保证复现，方向场应由固定输入确定，避免使用当前时间或无种子的随机数。

建议先在小块岩面上对照：皴线是否服从体积、是否有疏密变化、是否变成平行刷丝。再将有效组合用于完整画面。轮廓、明暗和皴擦方向共同决定造形，单项参数不能保证画面质量。

## 时间与渲染

各类笔触支持 `start`、`duration`，均以绝对秒数计；`duration: 0` 表示即时显示。渲染时使用：

```js
renderCanvas(ctx, builder.snapshot(), {
  time: 1.5,
  paperTexture: 0.06,
  clear: true
});
```

省略 `time` 表示显示全部完成的笔触。笔触按路径展开，墨洗按浓度渐入。默认每次清空重绘；`clear: false` 用于叠加，结果会受已有像素影响。`paperTexture` 为 0–1 的纸面颗粒强度，并非真实宣纸介质模拟。当前时间参数表达笔迹的显露进度，不等于已经验证了自然落笔或墨色扩散动画。

## 如何沉淀可复用方法

保留输入轮廓、场景种子、生成参数、场景快照与渲染结果。一次比较尽量集中在造形、笔触或材质中的一个问题，分别记录观察到的改善、退步和未验证范围。

WikiSkill 可以解释如何选择和组合这些工具；函数库提供可编辑的数据与执行能力。请让构图和笔势继续由创作者决定，避免把示例固化为所有作品共用的模板。
