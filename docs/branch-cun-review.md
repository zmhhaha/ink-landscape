## 数据与执行边界

三组仍使用版本`1`、生成器`ink-cun-guides-v1`的`CunDocument`，每条作者源笔生成一个普通`StrokeMark`，以`renderCanvas`绘制。新增`cloud-study / point-study / heye`仅选择接触和局部动作默认，全部路径、聚散、开口、交接与叠压顺序由作者提供。

`cloud-study`在作者环抱线上提供轻中侧与提按接触，不自动旋出同心云团；`point-study`在短笔路上提供轻触、按腹和收提，不决定点类皴法的历史分类；`heye`提供上重下轻与开收，不创建父子分支关系。三组均沿用平滑采样与`local-v1`，不是实际笔毫、运腕或材料过程。父子筋脉仍是独立源路径的作者组织，没有暗藏树状拓扑。

逐笔覆盖优先于公共和技法默认，显式`controls`整体替换默认局部控制。原始压力与零压力离纸段保留，稳定ID支持局部修改、保存与重建。时间按绝对时间显露既有笔迹，不模拟干燥；本批没有新增湿态交换、Shader或固定山体生成器。
