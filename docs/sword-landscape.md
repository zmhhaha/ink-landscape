# 剑峰与云海：完整场景研究

入口为 `/examples/landscape-study.html`，默认种子 `261119`、尺寸 `1280×800`。这一版将此前42笔岩石对照推进为完整构图，目标是锐脊、长劈与云根留白。传统技法名称仍指程序近似，工程检查不代替实际画面的评价。

## 几何与笔势

`examples/scene.js` 的 `geometry()` 仅使用纯数据和带种子的随机源，不访问浏览器。它生成10座高窄山峰，左右峰脊分别引入断肩、侧向撕裂和非线性展宽；所有节点保留折角。开放脊线与闭合裁切区域分别存储，底部不勾线。

默认峰体有226笔长劈和20笔结构底墨。长笔由峰内的结构脊起笔，沿下落方向拉开约56–284个参考像素，再提笔收锋。焦墨主要积在暗侧，亮侧留纸，仅以零散淡笔联系山势。这里没有把一个完整山体网格填满后再贴纹理。

`material()` 将每一笔绘到可复用的局部透明画布，在笔刷自身通过 `destination-out` 去掉不均匀斜横断口和断续丝束，再叠入山体。断白是透明区，会透出前面的墨层；多笔积墨仍可能填回部分飞白。背景为三层淡灰绿远山，左下为有干擦裂隙的焦墨岩岸与三株折干松，右上为红日和七只飞鸟。

云海是独立的 alpha 场，横向边界带有种子控制的起伏和局部云舌。它以 `destination-out` 擦除远山和山体，低处完全透明，中间渐隐。纸、松树、前景与红日飞鸟不经过这个遮罩。展开页面的诊断区域，可以直接对照擦除前、擦除后和实际遮罩。

## 数据重放

这是独立于通用 `InkScene` 的示例配方，尚未成为 npm 顶层 API。构建项目后可按源码路径使用：

```js
import { geometry, createLandscapeRenderer } from './examples/scene.js';

const data = geometry({ width: 1280, height: 800, seed: 261119 });
// data.peaks 中的轮廓、开放脊线和每笔 points 均可继续编辑。
// 示例笔路的压力字段为 p（0..1），不同于通用 InkPoint 的 pressure。
data.peaks[0].strokes[0].width *= 1.2;
const painter = createLandscapeRenderer(canvas, { data });
painter.render(6);

const saved = JSON.stringify(painter.describe());
painter.dispose();
const replay = createLandscapeRenderer(canvas, { data: JSON.parse(saved) });
replay.render(6);
```

`data` 可为 `geometry()` 的结果或整个 `describe()` 导出对象。恢复过程复制并校验数据，不按种子覆盖调用者编辑过的路径。`restoreLandscapeData()` 可在 Node 中独立恢复数据；页面提供 JSON 载入和导出按钮。自定义分组、空峰组和移动到原构图外的元素均按数据重新计算缓存边界。

## 缓存与确定性

初始化时，笔刷临时画布重复使用；每个山体分组、远山、前景和点景各自缓存为裁剪图层。它们构成场景图层缓存，而非每帧重新遍历上万条纹理路径。未启用诊断时，完成擦除后释放云海画布；`dispose()` 释放全部保留画布。

默认配方完整画面合成最多调用8次 `drawImage`；自定义峰群可增加图层数。绝对时间0–6秒控制缓存层从上到下显露和点景淡入，不模拟逐笔运笔、水墨扩散或物理干燥。时间输入顺序不改变结果。

缓存与输出首次取得2D上下文时固定 `willReadFrequently: true`，避免浏览器因读取像素切换栅格方式而改变透明度舍入。若调用者预先创建输出上下文，也应采用相同设置。固定版本、数据、种子、时间和画布后端可重复；HTML Canvas 与 OffscreenCanvas 的边缘栅格结果可能不同，跨浏览器、跨后端不承诺逐像素相等。

页面分别显示初始化和同步合成耗时。同步调用耗时不含最终显示提交，不能换算成帧率；缓存字节仅为保留画布宽×高×4的 RGBA 估算，不含浏览器资源副本、GPU内存或临时峰值。诊断模式额外保留两幅透明山体和一幅遮罩，资源开销高于正常使用。

## 检查与已知局限

运行 `npm test`、`npm run check`，并在浏览器点击“运行工程检查”。浏览器检查实际像素的乱序重放、同种子重建、JSON重放、编辑路径生效、遮罩羽化和底部完全透明，同时观察两种2D上下文的方法、缓存分配与释放。HTML 和 OffscreenCanvas 分别检查内部复现，二者之间的差异只记录为诊断信息。

主峰仍有连续积墨实块，部分小峰存在重复竖向组织；松树与远山也是简化图式。与此前灰壳短皴相比，这一版改变了造形、用笔、遮罩和场景关系，但还不能据此宣称传统大斧劈皴或目标参考效果已通过艺术验收。后续改进应继续以实际成图为依据。
