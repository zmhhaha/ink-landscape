## 公共源与调用

公开API `createStrokeGroupDocument(groups, options)` 保存逐组、逐笔作者源，返回 `recipe.generator = 'ink-stroke-groups-v1'` 和普通 `InkScene`。`compileStrokeGroupRecipe` 从JSON源重建；`reviseStrokeGroupDocument` 或替换某一源笔后重新创建，可编辑路径、接触控制、宽度、墨量和绝对时间。`parentId` 只记录作者的组织关系，不自动推断附着、遮挡或传统技法。

```js
import {
  createStrokeGroupDocument, compileStrokeGroupRecipe,
} from './dist/index.js';
import {
  remainingBrushBatches, auditRemainingBrush,
} from './examples/remaining-brush-fixtures.mjs';

const batch = remainingBrushBatches.find(item => item.number === 14);
const [study] = batch.make({ seed: 261134, layout: 'arc' });
const document = study.variants[1].document;
const saved = JSON.parse(JSON.stringify(document.recipe));
const rebuiltScene = compileStrokeGroupRecipe(saved);
const groups = structuredClone(saved.groups);
groups[0].strokes[0].points[0].x += 2.5;
const edited = createStrokeGroupDocument(groups, saved.options);
const audit = auditRemainingBrush(study); // { ok, checks: [{ id, pass, detail }] }
```

示例位于[remaining-brush-fixtures.mjs](../examples/remaining-brush-fixtures.mjs)。每批导出 `number/id/title/layouts/layout/make/audit`，`make` 返回三项study，每项有三个 `document` 变体。帧尺寸560×260，纸色 `#f5f2e9`，墨色 `#252820`；默认种子为 `261120 + 批号`。变体在同批同布局内使用同一输入种子，各笔身份再由公开API确定派生种子。全部使用 `local-v1` 接触前的作者源，最晚笔迹在8秒前结束。

连续行势在保存源之前由 `authoredPathTexture` 按约4场景单位间距采成曲线，附加幅度0.32以内的固定作者纹理；不是把七个远距节点连成硬折带，再靠密集线段掩盖角点。散锋围绕这一连续骨架给出各97站的独立束源。挫势只有一点内回调保角，前后曲线分别接入；书法长横、微曲竖、策与掠也保存连续源，磔则将连续捺身、明确捺脚节点和提收段分开，避免全局平滑消掉专门动作。

弧向采用随横坐标改变的弯曲坐标映射，折向采用分段转向的空间映射；它们改变局部切向及空间分配，不是把整图旋转。相同源点经相同映射，显式共享的分笔位置仍相接。朝向控制相对局部切线，因此换形后仍按笔路运作。作者可直接替换任意点、整笔或整组，不受这些展示布局限制。

`start/duration` 用于绝对时间显露。当前沿弧长显露，不含真实分段速度、笔毫惯性或驻笔沉墨；疾徐两项尤其保持三列总显露时间一致，检查可见改变是否来自作者接触假设。没有 `Math.random()`、墙钟动画或隐含浏览器状态。

## 第十三批：调锋、顺逆与散锋

| 研究与目录ID | 三列比较及动作依据 | 专门数据审计与局限 |
| --- | --- | --- |
| 37 偏移与复正 `brush-offset` | 持续偏侧 → 前段偏移后复正 → 两个换向处主动侧用再聚。保持原路径、原压力、墨色与宽度，只改变侧移和恢复位置。依据周星莲对外形分类的批评，以及现代教程对偏、侧合称的用词差异。 | `contact-recovers` 检查持续偏侧对照与复正控制末值，末列两次偏侧后回中；同一源几何不变。不设偏移阈值判定传统败笔，不把偏锋与侧锋强行分成两枚历史笔刷。 |
| 38 顺拖与逆推候选 `brush-follow`、`brush-against` | 同一行进方向顺拖 → 原路径逆推候选 → 起端逆入后主体仍顺拖。采用《运笔用墨》“顺逆”段，把起笔逆入和主体逆势分开。三列是方向／拖曳对照，不把某一种直接列为败笔。 | `direction-is-not-reversed` 核对三列作者点序完全相同、`drag` 独立变化及末列 `entry=concealed/drag=forward`。后向微移和接触负荷只是假设，尚非真实毛束受力；逆锋不必须飞白。 |
| 39 散锋聚散 `brush-split` | 等距等长梳丝反例 → 共同行势内异束接触 → 局部断续、聚拢与含墨差。依据故宫抱石皴条目中的破笔散锋、聚散分明，保留长短束之间的相续。 | `unequal-coupled-bundles` 比较宽度、实际长度与段数；候选束线有不同起止，围绕同一主势展开并在两端趋聚。显式细束不是笔毫物理，也不把这组接触实验直接命名为抱石皴或历史飞白书体。 |

三项的侧移、逆向微移与分束分别保留在不同层级，不能用同一种边缘噪声换名完成。散锋候选的白缝不是整笔等宽平行槽；束线仍可能在个别尺度显得规则，需要浏览器局部及用户评价继续判断。

## 第十四批：顿、挫与涩行

| 研究与目录ID | 三列比较及动作依据 | 专门数据审计与局限 |
| --- | --- | --- |
| 40 顿后再行 `brush-pause` | 等接触缓显对照 → 一处短尺度提、按、释放 → 顿处整理接触方向后续行。依据《续书谱》折欲少驻及乙瑛碑点的顿后行出。 | `press-release-and-continue` 检查压力峰两侧释放、峰后仍有行程，三列显露时长均3.6秒。停播时间不能自动产生顿势，不在每个节点制造墨珠，也不推断含水沉积。 |
| 41 挫势动作假设 `brush-reposition` | 只有按驻 → 一点内短回调后转入 → 回调与接触复正协同。依据《翰林要诀》“因前笔衄出”及《书谱》一点内的衄挫语境。 | `bounded-local-retreat` 检查作者源存在小于12场景单位的逆向短段，随后恢复主行；末列接触偏侧后复正。挫的微动作只部分支持，不把顿、挫、衄统一为抖动，不声称已经还原运腕。 |
| 42 涩行接触候选 `brush-resistant` | 满笔外露颤线反例 → 平顺骨架中局部接触负荷变化 → 换向处短暂增负后放行。依据刘熙载“涩非迟”和反对强效有形战掣的限制。 | `steady-source-variable-contact` 核对两种候选骨架相同、接触负荷有多级变化，三列枯润相同。候选不强制中心线随机抖动；隐含抵抗仍只是假设，粗糙、慢、干均不足以独立认定得涩。 |

顿的局部按驻、挫的局部回调、涩的连续接触组织分别有专门源审计。三项不能仅凭某个压力峰、尖角或噪点密度相互替代。

## 第二十八批：侧、勒与努

以下八法候选以苏霖编《书法钩玄·永字八法三》为主要语境，并与《翰林要诀》及白蕉对八法边界的讨论对读。没有据传承故事确认八法起源，也没有宣布八法是所有书体点画的完备分类。

| 研究与目录ID | 三列比较及动作依据 | 专门数据审计与局限 |
| --- | --- | --- |
| 82 侧点顾盼 `eight-ce` | 均匀斜印反例 → 顾右入腹、转收 → 点尾顾向下一横。保留短笔路的入、腹、收，不由“侧”直接映射侧锋开关。 | `dot-turns-toward-answer` 检查内腹压力峰、细出口及出口朝向下一横的点积关系。只比较这一具体点势与顾盼，未复原某件永字范字或腕法。 |

| 84 努竖微曲 `eight-nu` | 僵直柱反例 → 直中微曲、提按 → 竖势承接长短横。保留向下运行和小幅势向，避免强制香蕉弧。 | `controlled-downward-support` 检查持续下行及不等长横的结构承接。几何微曲不等于已经测得笔力；不把垂露、悬针、隶竖合成统一端帽。 |
