## 开发顺序

2026-11-20，按用户最新安排，先回修已有四组：①积墨、破墨、水破墨、墨破水、撞水；②雨点、豆瓣、钉头、米点、点苔；③披麻、解索、牛毛、斧劈、折带；④散锋、破笔点、抱石皴。随后再推进下列控笔与新增方法。第一轮18项的实际入口和评价边界见 [四组优化记录](existing-technique-revision.md)。

1. **先做枯木与控笔。** 从枝干叉口和洞口的勾皴组合开始，用原画稿、只更新木结组织、再加沿程耗墨三份同构图对照。随后在同一路径上独立验证提按、转折和落印密度，再研究副毫的转向与收束。
2. **将组织方法用到别的形体。** 在线皴和点皴的现有样片上分别验证岩脊、裂缝与分面的控制。丝毛先用颈侧或翼根的小样，水纹先用平水和绕石的对照。
3. **细化墨层与设色。** 检查积墨、破墨和撞水的含水阶段与可迁移范围。勾花点叶用已有原语组成一套花叶笔序。撞粉在独立粉层与加水事件可表达后试作。

## 数据、兼容与验收

- 数据与几何核心保持纯 TypeScript，可在 Node 执行，Canvas 2D 提供基准渲染。以上游方案的可观察行为作研究依据，使用本库数据模型独立表达。详见 [架构与边界](requirements.md#架构与边界)。
- 作者可供路径、区域、方向场、局部控制和附着点。输出复用普通笔组、可序列化笔路、稳定组与笔标识，以及显式墨层、粉层和水事件。保留原始作者输入及生成版本。方向场在生成时采样，配方保存可重放数据。新机制显式启用，旧配方按其生成器版本重建。 [笔组文档](stroke-group-document.md) · [墨层文档](ink-process.md)
- 固定输入、种子、版本、后端、画布及绝对时间应可复现。验证纯 Node 生成、JSON 重建、局部修改与绝对时间乱序重放。修改一个木结、丝毛束或水纹组时，核对其他组的标识与笔路。涉及渲染的改动用实际浏览器检查，并按仓库要求运行 `npm test` 和 `npm run check`。
- 对照图和配方记录原始输入、种子、后端、版本、尺寸和改变的变量。每项查看原尺寸与两倍局部，再换一条笔路或形体，确认结构方向、主次疏密、留白和墨色变化符合观察目标。沿用每批三项合成一张对照总览的展示方式。资料支持、工程结果、可见表现和用户艺术判断分别记录。

## 第一项实施：枝干勾皴与木结

2026-11-20，新增纯 TypeScript 的 `createBarkDocument()`、`compileBarkRecipe()` 与 `reviseBarkDocument()`，将枝干路径、局部枝径、双边轮廓、叉口和木结源编译为普通笔组。按分支与木结身份分别取固定种子，局部编辑保留无关组。洞口靠几何布置留白，叉口在指定侧生成零压力断口。接口及边界见 [枝干文档](bark-document.md)。

[三组对照页](../examples/bark-study.html)分别比较左侧主干叉口、右侧悬垂朽木洞口与斜干换形。前两处也以显式选项接回[完整画稿](../examples/bada-study.html?bark=structured)，替换对应旧笔，不重复叠加轮廓。原画稿入口保留，用于同构图观察。

工程检查、实际浏览器导出与图片学习框架中的静态出图分别取证。当前可确认结构输入、局部编辑和换形能够执行；墨团厚薄及与原作的笔墨关系仍需视觉评价。此项进展不表示后续提按顿折、沿程耗墨、副毫动力或整幅临摹的艺术验收完成。

## 《芥子园画谱》选读与结构研究

2026-11-20，按用户安排把《芥子园画谱／画传》加入持续学习。先记录具体版本、公开图版与原文定位，再将可见的结构规律转成现有可编辑笔组；初编年代、后印本书目与二次分发出处分别核查。原文、图示观察、算法假设、工程验证和艺术评价分别保存，木刻颗粒不作纸笔物理参数依据。详见[专题选读](learning/jieziyuan.md)及[机器可读记录](learning/jieziyuan.json)。

第一轮已选读树叶、山石、三远与泉水图式，先做三项局部：三株主副与互让、骨线分面与随面皴擦、附枝叶群与露枝空口。[同题及换形页](../examples/jieziyuan-study.html)复用 `createBarkDocument()`、`createSurfaceCunDocument()` 和普通叶触，不新增通用具名笔刷、不替换旧默认。控制组也是本轮作者源，不冒充上一版结果；改动变量及笔量分别记录。

下一轮先用图3核对单株叉口与木结，再在同一石形比较大斧劈、解索与米点组织；之后研究三远遮挡、云水通道及下垂枝叶。当前只有三个局部研究完成工程对照，未标记全书掌握或用户艺术通过。
