# 第22–27批：布褶造形与衣纹线组

2026-11-20，本轮继续每批三项、每项三列的研究节奏，共18个study，关联19个目录ID。橄榄与枣核共享同题研究，但保留各自的阅读依据与未清边界。样片源为[`remaining-line-fixtures.mjs`](../examples/remaining-line-fixtures.mjs)，统一入口是[第13–30批浏览页](../examples/remaining-review.html)。所有艺术判断待用户统一评价。

## 原创对象与三列含义

各项以同一组原创布褶作为衣纹替代物：两处支撑决定张力，布面下垂形成主褶，辅褶在主褶上分出，局部前折遮住后折。斜向双支撑、拱形收束和折肘承托三种布局分别改变支点、垂势、边缘和受力笔路，不是对一条曲线作旋转、缩放或换压力。这些布褶是二维作者源，没有自动人体、三维布料或真实材料受力解算。

第一列保留同一布面外缘，内部用无视支撑的等距平行线作为反例；第二列把笔路连到明确支点，并组织本项要研究的笔性；第三列再安排主次、辅褶与前后。列间同时改变对象组织与接触，不宣称是单变量实验。细线、挺线、圆劲线、短促线、宽窄线、硬折与枯接触分别研究，不能把十八描化为同一弧线上的十八条压力公式。

结构组`cloth`保存外缘和支撑触点；`fold-*`从支撑处起笔；`secondary-*`从父褶的实际源节点分出。后折的笔路在前折两侧明确省略，`front-fold`最后绘制。白处来自未着墨，不用白色填充盖掉后景。`parentId`记录作者关系，不推断或修复连接；用户移动一组后，仍需重新设计相接与遮让。

混描采用已读现代教学的一种淡勾、局部浓醒解释。末列的墨面由普通淡宽笔形成，浓醒先后与笔路都保存为逐笔源；它没有增加湿边流体或以古诀短注确证完整传统流程。白描不添加设色，减笔以作者选择的四条主褶保留两端支撑和中心垂势，不能由随机删笔冒充概括。

第22批64–66按用户提出的“过细、过于流畅、像钢笔”回修：中列和末列加重部分笔宽，把起按、行提、局部承压、释放再按与提收写成显式逐点压力。曲线中顺滑和涩阻片段交替，用共享`jitterPath`作小幅相关偏移、`varyPressure`作少量连续压力调制，结果仍是普通可编辑源。弧长压力关键点由作者明确插入，扰动函数本身不重采样；笔路端点、支撑根和辅褶共用的父源锚点保留。作者扰动键与材质种子分开，换材质种子不重排布褶。首列反例与第23–27批保持原版本。这里研究笔路与接触组织，未测量或还原实际笔毫阻力。

短线三项沿褶骨分段，线段的受力位置、长短与方向服从对象。钉头鼠尾不是每段先盖同样的圆点，撅头钉不是机械截断尖尾。橄榄／枣核不设置互斥长宽比或“唯一古法”曲线；柳叶与衣纹竹叶的形容不自动继承第十二批植物竹叶的结论。

曹衣的古诀转载与现代教学有人物归属和传承差异。这里选择注明来源的“贴体稠密衣褶”解释，以布面曲面作有限替代物，保留异说；不能据此宣称复原某一历史人物画风、真实湿衣或三维人体。战笔只用固定作者键生成有界、相关的细屈曲，主褶仍可编辑；局部抖动并非传统运腕证明。枯柴的干侧接触复用已有毛束执行能力，但另作衣褶组织，不继承乱柴皴或基础枯笔的艺术判断。

## 阅读依据与范围

逐项动作、适用对象、误区和出处定位见[勾描与衣纹学习册](learning/linework.md)。主要有明确正文支持的范围如下：

- 故宫[白描](https://www.dpm.org.cn/lemmas/240113.html)、[游丝描](https://www.dpm.org.cn/lemmas/241511.html)、[铁线描](https://www.dpm.org.cn/lemmas/241512.html)、[钉头鼠尾](https://www.dpm.org.cn/lemmas/240735.html)、[战笔描](https://www.dpm.org.cn/lemmas/240407.html)与[减笔](https://www.dpm.org.cn/lemmas/240333.html)提供各自可观察的释义，不给出本程序的数值配方。
- 故宫[马和之](https://www.dpm.org.cn/lemmas/241438.html)的短促迅疾及兰叶变化支持特定画家语境，不概括所有时代或全部兰叶线。
- [中国美术学院人物画教学](https://mskj.caa.edu.cn/info/1030/22861.htm)补充白描粗细轻重、衣褶动势及写意概括流程。
- [现代十八描教学转载](https://www.sohu.com/a/255548842_99941818)提供琴弦、行云流水、混描、橄榄、枣核、柳叶、竹叶、枯柴、蚯蚓等操作候选；未署原作者的转载保留部分支持，不当作古代唯一标准。
- [十八描古诀转载](https://www.sohu.com/a/722875877_121106842)中的秃笔、尖大笔、肥短撇捺等短注仅支持有限笔性；未作原刻本校勘。故宫[十八描](https://www.dpm.org.cn/lemmas/241509.html)主要确认名单，不能据列名推导十八套独占算法。

样片复用`createStrokeGroupDocument`，使用`ink-stroke-groups-v1`保存分组、父组、普通笔路、逐点压力、局部接触、墨量及绝对起止时刻。每组与每笔都有稳定ID，材质种子按身份派生。所有点在560×260画布内，最迟落笔结束为2.69秒；时间只控制显露，不按墙钟模拟干燥。

`batch.audit(studies)`和`auditRemainingLine(study)`返回`{ok, checks}`。专门检查包括：两端受力根、辅褶从父源节点分出、前折中心确实位于后折相邻源段缺口内、前折最后画、压力与宽度主次、短线尺度，以及混描局部醒线、减笔作者取舍、曹衣稠密线群和枯柴局部干侧接触。
