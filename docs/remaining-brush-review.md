## 公共源与调用

公开API `createStrokeGroupDocument(groups, options)` 保存逐组、逐笔作者源，返回 `recipe.generator = 'ink-stroke-groups-v1'` 和普通 `InkScene`。`compileStrokeGroupRecipe` 从JSON源重建；`reviseStrokeGroupDocument` 或替换某一源笔后重新创建，可编辑路径、接触控制、宽度、墨量和绝对时间。`parentId` 只记录作者的组织关系，不自动推断附着、遮挡或传统技法。

```js
import {
  createStrokeGroupDocument, compileStrokeGroupRecipe,
} from './dist/index.js';
import {
  remainingBrushBatches, auditRemainingBrush,
} from './examples/remaining-brush-fixtures.mjs';

const batch = remainingBrushBatches.find(item => item.number === 14);
const [study] = batch.make({ seed: 261134, layout: 'arc' });
const document = study.variants[1].document;
const saved = JSON.parse(JSON.stringify(document.recipe));
const rebuiltScene = compileStrokeGroupRecipe(saved);
const groups = structuredClone(saved.groups);
groups[0].strokes[0].points[0].x += 2.5;
const edited = createStrokeGroupDocument(groups, saved.options);
const audit = auditRemainingBrush(study); // { ok, checks: [{ id, pass, detail }] }
```

示例位于[remaining-brush-fixtures.mjs](../examples/remaining-brush-fixtures.mjs)。每批导出 `number/id/title/layouts/layout/make/audit`，`make` 返回三项study，每项有三个 `document` 变体。帧尺寸560×260，纸色 `#f5f2e9`，墨色 `#252820`；默认种子为 `261120 + 批号`。变体在同批同布局内使用同一输入种子，各笔身份再由公开API确定派生种子。全部使用 `local-v1` 接触前的作者源，最晚笔迹在8秒前结束。

连续行势在保存源之前由 `authoredPathTexture` 按约4场景单位间距采成曲线，附加幅度0.32以内的固定作者纹理；不是把七个远距节点连成硬折带，再靠密集线段掩盖角点。本次13–15批回修另将阻力骨架细采为1.6单位间距，显式保存 `jitterPath`／`varyPressure` 的确定性结果；散锋用 `splitBristles` 的中心束、外束和分段源，反例仍是各97站的等距梳丝。挫势只有一点内回调保角，前后曲线分别接入；书法长横、微曲竖、策与掠也保存连续源，磔则将连续捺身、明确捺脚节点和提收段分开，避免全局平滑消掉专门动作。

弧向采用随横坐标改变的弯曲坐标映射，折向采用分段转向的空间映射；它们改变局部切向及空间分配，不是把整图旋转。相同源点经相同映射，显式共享的分笔位置仍相接。朝向控制相对局部切线，因此换形后仍按笔路运作。作者可直接替换任意点、整笔或整组，不受这些展示布局限制。

`start/duration` 用于绝对时间显露。当前沿弧长显露，不含真实分段速度、笔毫惯性或驻笔沉墨；疾徐两项尤其保持三列总显露时间一致，检查可见改变是否来自作者接触假设。没有 `Math.random()`、墙钟动画或隐含浏览器状态。

## 37–45本轮局部回修

用户针对37–66的反馈中，本域落实37、38、39与42四项；40、41、43–45保留原动作研究，28–30批不变。本次使用共享[纯数据扰动工具](../src/perturbation.ts)，固定输入与种子决定所有源数据，不读取墙钟或隐式全局随机状态。

- 37只在转锋区先减压再聚束。侧移、接触朝向和压力用更多有界控制站衔接，最大名义笔宽不增加，避免恢复时骤然撑圆。
- 38在1.6单位采样的共同骨架上，用6.3与19.7单位相关长度、0.36与0.17单位强度的两层位移，再加至多0.26单位微小后滞；源压力与接触负荷另以非周期噪声调制。实际偏移由审计限制在1单位内，保留连续向前，不再使用旧 `drag: reverse` 的周期派生。随机扰动不等于传统逆锋的物理定义。
- 39中心束名义宽度10.4／11.2、透明度0.94，外束各自有宽度、墨量、长度及起收。共享散束工具保留分束的part身份；本页再给部分外束加小范围断口和短距离提收，断口以省略源段表达，中心不断开。束数7／8不等于最终笔段数，默认两列分别为10／16段，换种子后段数可变。
- 42候选改用8.7与28.3单位相关长度、0.27与0.13单位强度的两层位移，源压力与非等距接触负荷分别调制。中、末列使用相同微扰骨架，末列只在换向区增加短促负荷；大幅等频颤线保留为反例。微扰幅度不用于标定涩行质量。

局部控制仍可独立编辑。重点观察37收束是否过细或仍成团，38是否连续而不是断齿，39外束是否可读且没有变成围着黑线的等距刷丝，以及42在两倍局部中是否还出现周期边齿。工程断言只确认限定动作存在，不构成艺术认可。
