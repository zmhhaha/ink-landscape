## 架构约束与数据责任

沿用[需求说明](requirements.md)中的独立库定位：数据和几何核心使用纯 TypeScript，Node中可生成和编辑；Canvas 2D 为初版后端。调用者提供路径、区域和方向场，库提供可组合的执行能力。

编辑源保存“想怎样落笔”，生成结果保存“本次生成了什么”。Agent调整动作时修改编辑源并重新生成；重放既有结果时读取已保存笔迹。记录版本用于说明生成与重放范围，未知版本应明确报错，不能静默套用当前解释。

提按、接触朝向、锋尖与接触区的关系、枯润和接触覆盖应有各自可解释的作用。参数之间可发生有说明的联动，但不能让“侧锋”仅靠换成扁笔、“提按”仅靠调透明度、“枯笔”仅靠降低整笔浓度来完成定义。

固定输入、种子、版本、后端、画布和绝对时间应可复现。纹理不读取墙钟时间或`Math.random()`。时间显露与墨在纸内扩散是不同能力；首批先判断静态笔迹及其可编辑性。

## 首批三组的观察标准

各组使用同题对照，明确记录改变的变量，分别检查直线、弧线和急转笔路，再查看小型笔组。种子、尺寸、后端、纸面、墨色及未改变的控制条件保持一致。只在某条笔路成立的配方，应注明该范围。

| 组别 | 操作与可观察目标 | 重点反例和边界 |
| --- | --- | --- |
| 提按 | 在行进中改变接触，观察由轻入重、由重转轻时宽度及墨迹的连续关系；保持原路径与零压力离纸段；局部按提可以出现在不同位置。 | 全笔固定的头尾渐细曲线不能涵盖所有提按；放大线宽可能形成气球状鼓包；重按不必更黑，轻提不必更淡。 |
| 中锋／侧锋 | 记录锋尖相对接触区的位置、接触朝向与受压变化；比较同一路径上中用、侧用及二者转换；观察线到面的过渡和换向后锋势是否连贯。 | 圆头、对称轮廓或竖直笔杆均不足以单独证明中锋；扁椭圆、固定斜带也不足以证明侧锋；偏锋与侧锋的用词差异继续注明。 |
| 枯润／飞白 | 固定墨色比较接触连续性与露纸；白丝的聚散、断续和走向应随笔路与接触变化组织；一笔中由润到枯的变化应能局部调整。 | 干湿与浓淡分别观察；避免等距梳齿、矩形网格、均匀点洞、固定宽度平行白线；湿笔的一圈模糊不能代替滋润笔迹及层次。 |

### 已读依据与使用范围

1. 提按：[《书法入门：运笔用墨》](https://www.9610.com/xiezi/bimo.htm)“提按”段给出提细按粗及连续变化的入门说明；[《怎样临习〈乙瑛碑〉》](https://www.9610.com/qinhan/yyb/01.htm)的波捺、捺点示范说明重按与渐提处于具体流程；[陈绎曾《翰林要诀》公开转录](https://www.9610.com/lilun/chenyiceng.htm)“肉法”把提按放在疏密、平险关系中。现代教学与古书转录分别标识，古文中的“分力”不作为传感器压力标定。
2. 中锋／侧锋：[姜夔《续书谱》公开节录](https://www.9610.com/lilun/jiangkui.htm)“用笔”节的“常欲笔锋在画中”支持锋尖与点画的运行关系；[周星莲《临池管见》公开转录](https://www.9610.com/lilun/zxl.htm)开篇讨论杆直与毫卧、藏露与中锋，以及“以侧势取其利”的画石用途。公开转录未做版本校勘，不能据文字推导统一笔杆角度或完整笔毫物理过程。
3. 枯润：[故宫“渴笔”](https://www.dpm.org.cn/lemmas/240331.html)与[“湿笔”](https://www.dpm.org.cn/lemmas/240210.html)分别从笔中含水状态解释干湿；[“墨分五色”](https://www.dpm.org.cn/lemmas/240484.html)说明浓淡、干湿等变化的不同分法。程序中的接触覆盖、枯润和透明度应说明各自范围，不能宣称它们已经测量或还原真实含水量。
4. 飞白：[故宫“飞白”](https://www.dpm.org.cn/lemmas/240500.html)说明线条“丝丝露白”的形态，并区分历史书法语境与今人泛称干枯笔触。本批研究可见的顺势断白，历史飞白书体的复原仍需另立目标和作品依据。
5. 作品用例：[故宫《程邃山水图轴》馆藏说明](https://www.dpm.org.cn/collection/paint/231388.html)提供枯笔焦墨、渴笔干墨行线与金石意味的具体分析。此前学习记录只确认阅读了文字说明，尚未完成该作品的高清局部对照，不能把此链接写成已完成的图像相似度验证。

详细动作、误区和出处定位保存在[运笔与书法学习册](learning/brush-calligraphy.md)与[墨法与水法学习册](learning/ink-water.md)。这些阅读结论提供观察依据；实际毛笔局部的可访问参考、观察范围和样片比较仍需逐批保存。

### 既有原型暴露的问题

[此前基础用笔观察](brushwork.md)记录了湿笔灰色丝带、硬边、急转拼接、枯笔梳齿与碎叶纹样。[局部实验记录](brush-study.md)还保留了平滑改变折角、干笔平行长丝和整体造形收益有限等限制。这些是本轮需要重查的失败表现，不能因增加参数或成功生成新图而自行划去。

已有起收、转折等几何原型仅作为后续组合的工程基础。它们并未因此获得本轮的艺术认可；新接口也不能通过保留传统名称自动继承艺术验收状态。

## 分批验收与Agent消费

每批记录以下内容：来源与观察范围；编辑源和生成结果；尺寸、种子、版本与后端；同题对照和换形结果；组合效果；改善、退步和未解决问题；工程检查结果；用户的艺术判断及适用范围。

工程检查覆盖纯Node生成、输入不变、JSON重建、编辑后重生成、绝对时间乱序定位，以及实际浏览器的绘制与交互。像素发生变化可证明变量生效，不能独立证明变化合理或技法成立。艺术待评、有限范围通过和退回继续打磨应如实记录。

首批三组的回修前归档样片曾获用户“看起来效果不错”的视觉认可，允许继续下一批。这项认可限定于当时展示的弧线对照图和回修前版本；直线、急转及其他参数范围的工程检查不自动转为艺术认可。它未补足真实毛笔控制实验，也不等于所有传统用法或完整山水组合已经通过。默认推荐给创作Agent的能力仍应关联已确认的适用范围与版本。

此前用户要求继续分批补齐，并在计划完成后让其他Agent查看；其后所说“一组一组出图”曾被助手误解为每个技法单独发图。用户已澄清“我说的逐组出图，是按照之前的三个一组的来”。据此每批三个技法，合成一张对照总览展示，工程检查和已知局限仍逐项记录，不请求即时艺术验收；最终评价及其他Agent查看由用户安排，不由当前样片或内部工程检查代替。

实际Agent的最小消费闭环继续保留：调用认可范围内的组合生成局部创作，按技法含义修改其中一笔，保存编辑源和生成结果，再重建并重放。该闭环单独保存执行证据；浏览器示例成功仅是独立库证据，不阻塞当前按用户指示推进的下一批。

2. 第二批已提供起笔、收笔与转折三组，分别研究逆入、露入、回收、出锋及换向调锋，见[第二批观察记录](gesture-review.md)。第三批已提供点迹的单点动作、横竖斜点势和成组关系，保留调用者显式落点及逐点编辑，见[第三批观察记录](dot-review.md)。各批工程检查与用户艺术判断分别记录。
3. 第四批提供浓淡、积墨和破墨三组，保留作者笔组、层次、浓度、水分、先后及有限湿态交互，见[第四批观察记录](ink-review.md)和[墨层程序](ink-process.md)。积墨中的墨量、覆盖与留明变化分别说明，破墨区分干后叠加与未干浓淡互破；这些程序条件不等于真实材料模拟。第五批提供水破墨、墨破水和分散加水三组，显式区分清水与墨事件、作用范围和逐滴身份，见[第五批观察记录](water-review.md)与[清水事件程序](water-process.md)；洒水仍是部分支持的研究范围，渍水、撞水、皴水不顺带认定实现。第六批用显式笔路研究披麻、斧劈和折带，保留错落、交搭、扫劈与折转的作者组织，见[皴法记录](cun-review.md)与[皴法文档接口](cun-document.md)。后续继续按依赖扩展，每批三个技法合成一张总览，艺术最后统一评价。披麻、斧劈等需要笔组组织和对象结构，分别建立验证范围。点迹用于点苔或点叶时也另行研究对象组织，不直接继承书法点群的结论。100条目录继续作为知识地图，不把同义术语或待确证条目机械拆为100个函数。
4. 第七批继续线皴，分别比较解索屈曲穿插、乱柴直折交错、牛毛细线的疏密留脉，见[线皴记录](line-cun-review.md)。三项沿用显式源和可编辑皴笔文档，牛毛只作部分支持的形态研究，不把缩细或增加曲率当作传统技法已成立。第八批接着以共享研究入口比较卷云／云头的环抱与搭接、雨点／豆瓣的短点聚散，以及荷叶的主次筋脉，见[第八批记录](branch-cun-review.md)。相近名称资料逐名保留，当前不裁定同义或虚构互斥预设；环抱线、点群与父子筋脉继续由作者显式供给。第九批先把点笔与细线用于石脊、枝架和叶簇，研究点苔、点叶与夹叶，保留作者显式的结构线、单叶路径和成对叶边，见[第九批记录](vegetation-review.md)。夹叶仍是部分支持的形态研究，不因有入口就改为完整传统技法。第十批比较介字与个字的分向叶组，并以攒三聚五研究变数、错落与空白通道，见[第十批记录](leaf-cluster-review.md)。三项共享普通点叶接触而保留不同的作者笔组；图式与笔序证据有限，不固化字形、笔数或历史参数边界，品字点仍保留待核。第十一批把细粒密簇、相关分束和针束扇向分别组织为胡椒点、破笔点形态及松针组织研究，见[第十一批记录](pepper-broken-pine-review.md)。破笔点与松针的阅读仍部分支持，显式束源不代替真实散锋接触或针序验证。第十二批另以竹枝与尖长叶笔研究疏密穿插，以短叶围攒研究梅花点叶，以显式双边轮廓研究绘画双勾，见[第十二批记录](bamboo-plum-outline-review.md)。三项复用普通文档，不新增同名历史固定笔头；竹叶与梅花点资料仍部分支持，梅花点非梅花实物，绘画双钩非复制法帖。双边内区保持透明，遮挡后缘由作者路径分段明确省略；品字点仍待图式核实。随后将有效方法继续组合到山石、树木及完整画面中，再验证连续运动；计划内各批完成后由用户安排其他Agent统一查看，复核意见再回到对应批次处理。
5. 完成实际Agent调用、修改、保存与重放闭环。额外后端、正式制作消费和知识发布分别沿用[需求说明](requirements.md)中的独立验证与发布安排。
