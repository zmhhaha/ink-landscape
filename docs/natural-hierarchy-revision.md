# 自然组织回修

2026-11-20，继续按用户对编号01–60的评价，回修笔触主次、局部顿转承墨、湿边与墨渣、点组聚散、叶片正侧及双勾提按。第21–30批不主动迁移；规整的负面对照继续承担比较作用。

新增[纯数据作者工具](natural-authoring.md)：一维与二维梯度噪声、归一化fBm、带输出预算的泊松锚点，以及接触内缘带权重。泊松约束组间锚点，组内仍可叠墨；结构、附枝根和遮挡先后保持显式。

墨层与水事件提供可选`edgeDeposit`和`edgeWidth`。局部边缘加深来自对已有整层覆盖的重分配和归一化，清水不会新增颜料；省略强度或设0保持旧覆盖。原有有限湿窗前沿迁移继续负责湿墨交换，未使用最终图的高斯模糊替代该过程。46焦墨与59拖泥带水的已评价源继续保留。

笔域把39改为实主毫与短、细、断续的外毫，40–42只在显式顿转窗口增压承墨；结构域增加点组主次、正侧叶片和双勾起重收尖，枝架、附枝根、身份及先后仍由作者源给出。湿边采用多尺度扰动与局部密度重分配，47增加团聚沉渣，49–50在染边加入独立扫触，60用不等主毫和有界长度变化组织散束。规整负面对照保留，未把所有对象统一加噪声。
