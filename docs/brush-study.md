# 基础笔法局部实验

2026-11-19。本轮对应基础用笔的转折与枯笔断白研究；继续采用 Canvas 2D。工程实现、局部改善和传统技法验收分别记录。

## 改动与固定条件

新增可选 `smoothing: 'catmull-rom'`：向心 Catmull–Rom 插值、近似弧长采样和解析切线法线，控制点间的压力变化使用缓动。省略该字段仍保留折线；预览页默认选择平滑。纯 TypeScript 的 `sampleStrokePath` 可供其他后端使用。

飞白不再按等距丝束铺排，而采用不同位置、宽度、游移及局部接触长度；少量宽墨束与细丝共同保留墨量，较干参数减少连续底墨。所有变化由固定种子与笔路弧长确定，不使用时间随机数，也不擦除已有笔迹。

局部样片固定种子261119，每片600×260，纸纹0.025，完成时间3秒。圆锋宽34、侧锋宽52，枯润0.28；换形使用急转和不等距控制点；枯润梯度为0.20／0.55／0.85，固定纹理种子8642；岩面组合包含34条短皴、3条骨线与1层淡墨。可在 `/examples/brush-study.html` 查看并导出 PNG、场景 JSON，源码在 `examples/brush-fixtures.mjs`。

仓库外另保存原版渲染器，基线为 `e9f5856838931ee3dfaca75d09e564c33f29901e`。三列比较分别为原版折线、新材质折线、新材质平滑；每列使用相同控制点、压力值、种子和透明度。前两列观察材质变化，后两列观察笔路与压力插值变化。主试验台的折线选择使用当前材质，不代表完整旧版。

## 实际观察与限制

- 转折：圆锋与侧锋的阶梯法线和接缝明显减少，换形后仍可观察到改善。急转也会被圆化；需要棱角时保留折线。平滑曲线可能越出控制点范围，区域边界应由 `clip` 限定。
- 飞白：第一轮减少了短线网格，但失墨偏多，转为少数长丝和双轮廓。第二轮缩短接触长度并增加少量短宽墨束，中枯的墨量与断口更明确；仍存在平行带状、长丝和局部机械感，不能认定真实飞白已验收。
- 迁移：急转笔路与短皴岩面均完成实际渲染。小岩面可显示笔势变化，但仍偏平底墨加细线，尚未建立自然的传统皴法表现。
- 整图：同条件山水组合的变化有限，山体造形、体块、平直云带及虚实关系仍需独立打磨。本轮不能证明整幅画达到参考目标。
- 兼容：旧 JSON 仍可读取；材质算法已改变，渲染外观会变化。复现需固定源码版本、场景、种子、尺寸和后端。

这些结论来自本轮实际局部与整图对照，尚无开发者的艺术认可，也未新增传统技法参考相似度验收或连续运动验收。OpenSpec 的完整基础用笔、皴法和整图任务仍不能由本轮直接签收。

## 工程验证

`npm test` 23项通过，`npm run check` 通过。新增检查覆盖端点、压力边界、法线连续与单位化、不等距控制点、重复点、回折、输出数量限制、有限大坐标的溢出、序列化和旧场景兼容。Canvas 测试同时覆盖两种笔路的乱序绝对时间、JSON 重建和调用者状态恢复。

真实浏览器检查覆盖四类主示例与六组局部样片：相同时间重复定位及 JSON 重建均得到一致像素；主示例还检查重建、种子和插值变化。主台实际切换笔路及山水组合后，`6s → 2s → 6s` 像素一致。检查入口为 `/examples/verify.html`。这些检查验证可重复执行，不验证自然落笔动画，也不承诺跨浏览器逐像素相同。

## 性能观察

本机 Windows、Chrome157、DPR1、1280×800、Canvas 2D，同一316标记山水场景；默认2D上下文，未请求 `willReadFrequently`。每项预热2次、测量9次同步 `renderCanvas` 调用，包含清屏、纸纹与绘制，不包含场景生成、像素读取、截图和显示提交。以下为一次同条件比较，P95在9次样本下即最大值：

| 版本 | 中位数 | P95 |
| --- | ---: | ---: |
| 原版折线 | 40.8ms | 42.7ms |
| 新材质折线 | 56.7ms | 60.0ms |
| 新材质平滑 | 60.9ms | 66.9ms |

新实现增加了材质计算与局部填充，此样例下有明确耗时增加；本轮未证明提速。316个标记可完成绘制，不能据笔数断言通用上限，也不据这些同步耗时声称帧率。验证页另外记录 `willReadFrequently: true` 下的生成与渲染中位数／P95，不能与上表混用。未测量 GPU 利用率或峰值内存。
