# 前十二批笔墨与组织回修

2026-11-20，按用户对前十二批总览的观察进行一轮回修。主要问题是边缘过净、压力与形体过度对称、分束像排线、水墨交区偏平均，以及叶簇与枝架脱节。[统一浏览页](../examples/revision-review.html)仍按每批三项、每项三列展示，可换形、导出PNG与完整源记录，再进入各批试验台继续逐笔编辑。第十三批暂缓。

后续[第二轮回修](hierarchy-water-growth-revision.md)已更新统一浏览页的当前样片；本记录的代码范围、158项测试与图片证据仅对应首轮归档，不代替第二轮的验证结果。

## 建议的采用范围

毛边、笔压、分束和不对称需要随接触与作者结构变化。已有压力接触采用非线性展开，本轮不再以强制所有调用传压力数组来改接口；修改样例的压力过程，同时保留调用者自己的路径、零压力、局部控制与默认值。侧锋两侧不同沉积是本次可调的材质近似，不把某一侧永远光滑、另一侧永远锯齿当成传统定义。

所有纹理使用固定种子与关联噪声，绝对时间只揭示同一笔迹。没有引入Math.random、墙钟噪声或逐帧随机抖动。长线的微偏移属于作者明确保存的源点，起止、关键节点与枝叶根部有各自的约束；细线不统一增加固定像素的抖动。

原墨层已经累加光学深度，并以exp(-density)转成透射率；同色透射率的乘积与光学深度相加相对应。本轮保留这一机制，改进接触沉积、后层枯润与湿交界，不叠加一个只改变Canvas混合模式的开关。水墨交换继续守恒、非负、局部且有声明湿窗，清水自身不着色或擦墨；种子纸面导流与不等前沿仍是有限事件近似。

散锋用不等宽墨束、束内分支和断续接触表达；并非固定根数细线是唯一正确算法。点群、乱柴与枝叶的分布先由作者给定，保留阴阳、主势、空白和连接关系；本轮没有用无条件泊松盘或高斯随机点群替代这些责任。首列机械反例在相应组织对照中继续保留，后两列研究有意的变化，不要求每格都变成同一效果。

## 各批处理

| 批次 | 本轮处理重点 |
| --- | --- |
| 1：提按、中侧、枯润 | 作者压力改为不对称的加载与释放；湿体两侧分别形成毛边，偏侧接触一侧更断续，干段由不等墨束露纸。 |
| 2：起笔、收笔、转折 | 起收各束错开，避免整齐切口；作者主体压力有轻重与渐收，角点压力有差别；保折与圆转的局部动作仍分开。 |
| 3：单点、点势、群点 | 点体共享新的毛边与墨束沉积，短点采用偏后的压力峰、偏侧点腹和后段聚墨，方向三列仍只改变角度；组织列的疏密、方向与局部墨聚分别保存。 |
| 4：浓淡、积墨、破墨 | 保留浓度对照与光学深度累加，叠墨后层渐干；多尺度纸面接触与局部湿边形成不同咬合。 |
| 5：水破墨、墨破水、分散加水 | 有限湿交区内形成不等导流前沿与留墨，仍区分水墨先后、过窗与逐滴编辑；细节绘制网格从2改为1。 |
| 6：披麻、斧劈、折带 | 披麻先用穿过原节点的连续曲线再加法向微扰，避免直线稠密化锁住折角；面笔使用不均匀分束，折带保留原关键点与圆转／方折对照。 |
| 7：解索、乱柴、牛毛 | 弱化周期曲线和等间隔；乱柴保持方向与空白通道，细线偏移随宽度受限。 |
| 8：环抱、短点、荷叶 | 环抱与筋脉保留关键交接，短点形成局部聚散；相近名称继续保留共享研究入口和资料边界。 |
| 9：点苔、点叶、夹叶 | 点苔沿石脊内侧组织，单叶与成对叶边的根部落在显式枝架上，细线内区透明。 |
| 10：介字、个字、攒聚 | 近根组织主长侧短与偏势，削弱风车般等角对称，组间保留空白通道。 |
| 11：胡椒、破笔、松针 | 细粒点簇、相关散束与针束使用不同的作者组织，弱化等角重复，保持枝端连接。 |
| 12：竹叶、梅花点、双勾 | 叶势与短叶围攒削弱等角重复；双勾使用更有变化的细线沉积，保留作者显式的遮挡缺段。 |

## 版本与评价

公开数据接口与生成器标识保持原有含义，样例源按本轮编辑重新保存。接触和墨层绘制代码改变，同一份旧JSON在新绘制代码下的像素会改变；精确重放旧像素需要原后端及源码快照。2026-11-19各批归档和用户已看图片保留，2026-11-20回修证据独立归档，不覆盖旧图。新浏览页源记录另记canvas-contact-grouped-20261120后端标签。

首批旧图的有限视觉认可不延伸为本轮回修的认可；目录仍为unreviewed。没有新读图、连续运笔视频、实物材料实验或历史版本校勘。工程检查只能确认行为与保存合同，艺术效果由用户比较后评价。

## 工程验证与证据

最终源码通过`npm test`的158项测试及`npm run check`。实际浏览器检查覆盖12批、36种布局选择、324个样片，检查源数据与JSON重建、固定输入与种子、输入隔离、时间重放、零压力和各批编辑约束。末次作者曲线与点迹调整后，第3、6、7、8批另行复查，合并结果以归档的`browser-checks.json`为准。

组织源审计检查216份文档、27次整组编辑，38,409个皴与植被源点全部在各自画布内。统一页实际下载36份记录，每份9个完整文档，共324份；保存记录重新编译与保存结果严格相等。独立地在Node与Chromium中重新运行样例工厂时，三角函数等运算可能有末位差异，因此工厂对比使用绝对误差上限`1e-10`并记录实际差值，不宣称跨运行时生成坐标逐位相同。

十二张新版PNG均为1760×1840，每批三项九格并附两倍局部。旧图来自2026-11-19原始归档，尺寸和排版可能不同；前后对照只供视觉评价，不作同布局像素差分。证据、公开源码快照、Git状态、图片包与SHA256清单保存在`D:/codex-work/archives/ink-landscape/20261120/twelve-batch-material-revision/`，不写入公开项目。

## 可见局限

本轮减少了均匀灰套边、规则纤维排线和枝叶脱节，长线也保留了圆转。部分湿笔内部仍有贯穿亮纹，枯段的白隙较宽，斧劈局部仍可读成轮廓层纹。水法列间变化偏细，灰色大面与有限网格前沿仍可见；这不是连续流体或真实纸张干燥模型。点、叶与针束仍能看出共享程序母形，枝架也是稀疏研究骨架。以上均留待用户比较新版图片后继续评价，工程通过不等同于笔法或艺术通过。
