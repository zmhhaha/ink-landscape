## 观察标准与对照责任

| 组别 | 研究动作与可观察目标 | 重点反例和边界 |
| --- | --- | --- |
| 起笔 | 同一主体笔路比较直接露入、短促逆入再转向主体，以及起笔动作与接触用锋的组合；通过锋尖叠层核查实际行迹。 | 统一圆帽、外露小圈或墨团不能证明藏锋；逆入取势不等于整笔逆锋运行。露入也不只有一种三角尖外形。 |
| 收笔 | 同一主体笔路比较保持作者收端、边行边提，以及尾部短距离回收；观察收束方向、宽度递减与主体的连贯关系。 | 压力突然归零、附加黑刺、装饰性鼠尾、肿大的回钩都需单独排查。圆端不等于回锋，回锋也不要求整段倒走。 |
| 转折 | 比较作者保留的折角、连续圆转，以及在相同转接过程上叠加提按或接触方向变化；检查内外缘、两段贯通和折后出势。 | 全局平滑会改变作者棱角；折线节点本身不能证明折笔。每个角都加同样墨团、用时间停顿解释静态几何，均超出当前模型。 |

每组要注明各列改变的动作或控制，组合列应保留上一列已有动作再加入说明的变量。直接露入与逆入、渐提与回收等互为不同动作的对照，不应伪称它们只差一个物理量。种子、尺寸、纸面、墨色、未列出的动作和接触状态保持一致。

换形要覆盖不同方向、曲率和转接关系；原始作者路径与动作生成路径分别保存。当前的动作控制是空间几何与接触近似，`start`、`duration`仍只驱动路径显露，不表示实际速度、驻笔积墨或毫束弹性。

## 使用与保存边界

继续使用 `createBrushDocument` 的原始笔路、动作设定、局部控制、生成器标识和编译结果。本批显式使用`gestureModel: 'local-v1'`和生成器`ink-brush-local-gestures-v1`。旧默认`legacy`与`ink-brush-contact-v1`继续保留，首批不迁移；编译拒绝生成器与模型不匹配的文档。

新模型的圆转只在转角附近插入二次贝塞尔段，保留长直行段；保折保留转点并组织局部提按。结果离散化后使用`linear`，不再被全局Catmull-Rom重新平滑。满强度`strength: 1`时，露入从零压力进入，提收在终点减至零压力，回行收束在短回行后减至零压力；中间强度混合动作，零强度不施加动作。保留作者Catmull-Rom笔路时先采样曲线并保留源零压力节点，再输出`linear`结果。这些均为注明版本的几何动作，不代表毫束弹性或笔速过程。

起笔、收笔或平滑改变生成路径后，局部控制的 `at` 仍按生成路径的归一化弧长解释，不是作者点编号或时间。旧结果的重放和编辑源的重新生成各有责任，详见[接口说明](foundation-brush.md)。

几何动作可能局部超出作者路径范围；精确区域限制应由调用者提供 `clip`。短路径、重复点、零压力、不同方向以及动作强度都需要工程检查，不能仅以默认横画的效果判断可迁移。未知版本应拒绝，而不是静默按新解释编译旧记录。

## 本批验证与待评事项

`npm test`的68项测试及`npm run check`通过。测试覆盖纯Node的局部动作、默认旧算法的固定结果、编辑源重编译、模型与生成器匹配、短路径／重复点／零压力及有界输出。默认与显式`legacy`继续保留已有结果；新模型显式选用，不迁移首批。

真实浏览器核验三种布局共27个第二批样片：保存结果与语义重编译一致，同版本JSON重放、乱序定位后像素一致；组内动作隔离、源路径不变、零强度时接触控制独立、零压力不落墨、满强度端点离纸及两笔组合均通过。首批27个样片的原有浏览器检查也再次通过。检查只证明列出的工程行为，不作艺术评分。

交互实际操作了三个滑杆、布局选择、锋尖叠层、整批11笔JSON载入，以及拒绝生成器／模型不匹配和源／结果不一致的文件。导出JSON与PNG按钮已触发，未检查浏览器下载文件内容；未据此把下载文件完整性写成通过。浏览器检查未记录警告或错误。

看图后的调整包括：圆转只替换转角局部，保留长直段；露入和提收以连续多站压力过渡；回行先渐提缩小接触再内收，减轻细干斜笔尾端的空心折钩。每格增加原图起端、尾端或首个转角的两倍放大，便于比较局部。

仍存在的限制：逆入与偏侧接触叠加时起端可见局部小突起，回收和提收的外轮廓在某些路径上相近，飞白仍带程序线束感。当前先验证可编辑的动作及有限形态，不据此认定藏锋、回锋或调锋的传统全义成立。两倍放大也只扩大实际程序图像，没有补入参考笔迹或重新绘制细节。
